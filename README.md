Lumenkeeper — you are the keeper of the last lantern. Shadow wisps drift in from the dark
to snuff your flame; burn them in your light, gather golden motes to feed it, and survive
all 10 waves. A complete 2D canvas game: mouse or WASD movement, flare bursts, procedural
WebAudio sound, title / pause / victory / game-over screens, and a best score.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
